# Spring MVC Calculator

A simple Spring Boot MVC calculator using Java 17, Spring MVC, and Thymeleaf.

## Features
- Addition, subtraction, multiplication, and division
- Division-by-zero validation
- MVC architecture: Controller, Service, Thymeleaf view

## Requirements
- JDK 17+
- Maven 3.6+

## Run
```bash
mvn spring-boot:run
```

Open http://localhost:8080/

## Package as JAR
```bash
mvn clean package
java -jar target/spring-mvc-calculator-1.0.0.jar
```
